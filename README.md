## 👋 About This Portfolio

A **fully hand-coded personal portfolio** built from scratch — no templates, no frameworks, pure HTML + CSS + JavaScript. Designed with a dark glassmorphism aesthetic, aurora blob effects, an interactive solar system skills map, 3D flip experience cards, and a cinematic hero section with custom cursor and particle canvas.

> *"The best engineers I admire don't talk about what they'll build. They show you what already runs."*

---

## ✨ Features

| Feature | Description |
|---|---|
| 🌌 **Aurora Background** | Animated floating blobs with CSS radial gradients |
| ✨ **Particle Canvas** | JS-driven floating particle field |
| 🖱️ **Custom Cursor** | Dot + ring cursor with magnetic hover effects |
| 🔠 **Typewriter Hero** | Animated role cycling using a vanilla JS typer |
| 📊 **Counter Stats** | Animated number counters on scroll into view |
| 🪐 **Solar System Skills** | Interactive orbiting planets for 27 skills across 5 categories |
| 🃏 **3D Flip Experience Cards** | CSS 3D perspective flip cards for work experience |
| 🎠 **Project Carousel** | Smooth slide-based project showcase with browser mockups |
| 📜 **Timeline Education** | Reveal-on-scroll academic timeline |
| 🏆 **Certification Carousel** | 11-card coverflow carousel with keyboard + swipe support |
| 📬 **EmailJS Contact** | Working contact form with zero backend via EmailJS |
| 📱 **Fully Responsive** | Mobile-first hamburger menu with full-screen overlay |
